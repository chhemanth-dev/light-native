# What's New in Light Native

## ✨ Latest Update

### 🔑 In-App API Key Management
**No more rebuilding when your API key runs out!**

You can now change API keys directly in the app:
1. Go to **Settings** → **AI Provider & API Keys**
2. Paste your new key
3. Tap **Save Keys**
4. Done! Works immediately.

**Supported Providers:**
- ✅ OpenAI (GPT-4) - Recommended
- ✅ Claude (Anthropic) - Best reasoning
- ✅ Gemini (Google) - Fast & free

**Security:** Keys are encrypted and stored only on your device.

## 🔧 Technical Details

**Platform:** Android 8.0+ (API 26+)
**Framework:** React Native with Expo
**AI Providers:** OpenAI GPT-4, Claude 3.5, Gemini 1.5
**Storage:** Encrypted SecureStore for keys, SQLite for data
**Permissions Required:**
- 🎤 Microphone (voice commands)
- 🔔 Notification access (read notifications)
- ♿ Accessibility (send messages)
- 📞 Phone (make calls)

## 🐛 Troubleshooting

**"API key not configured"**
→ Go to Settings → AI Settings → Add a key

**"Credit balance too low"**
→ Add credits to your account or change API key

**App not responding**
→ Check internet connection and API key status

**Can't send messages automatically**
→ Enable Accessibility Service in Android settings
