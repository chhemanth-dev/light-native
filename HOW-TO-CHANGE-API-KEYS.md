# How to Change API Keys in the App

**Good news!** You can now change API keys directly in the app without rebuilding. This is useful when:
- Your API key runs out of balance
- You want to switch to a different account
- You want to add multiple provider keys

## Steps to Change API Keys

### 1. Open Settings
- Tap the **Settings** tab (⚙️ icon at bottom right)

### 2. Go to AI Settings
- Under "AI ENGINE" section
- Tap **"AI Provider & API Keys"** → **"Manage →"**

### 3. Update Your Keys
You can add/update keys for:
- **Gemini** (Google) - Free, fast responses
- **Claude** (Anthropic) - Best reasoning
- **OpenAI** (GPT-4) - Advanced tasks, recommended

### 4. Paste Your New Key
- Tap the input field for the provider you want
- Paste your new API key
- Tap **"Save Keys"** button

### 5. Done!
✅ The new key is saved securely and used immediately
✅ No need to rebuild the app
✅ Keys are encrypted on your device

## Where to Get API Keys

### OpenAI (Recommended - $5 free credit)
1. Go to: https://platform.openai.com/signup
2. Sign up for free account
3. Go to: https://platform.openai.com/api-keys
4. Click "Create new secret key"
5. Copy the key (starts with `sk-proj-` or `sk-`)

### Claude (Anthropic)
1. Go to: https://console.anthropic.com
2. Sign up for account
3. Navigate to API Keys
4. Create new key
5. Copy the key (starts with `sk-ant-`)

### Gemini (Google)
1. Go to: https://makersuite.google.com/app/apikey
2. Sign in with Google account
3. Click "Create API Key"
4. Copy the key (starts with `AIzaSy`)

## FAQ

**Q: What happens to my old key?**
A: It gets replaced. You can keep using it in other apps if you want.

**Q: Can I use multiple providers?**
A: Yes! Add keys for all three. The app will try them in order if one fails.

**Q: Are my keys safe?**
A: Yes! Keys are encrypted and stored only on your device. They never leave your phone.

**Q: Do I need all three keys?**
A: No, just one is enough. OpenAI is recommended for best results.

**Q: What if I forget which key I used?**
A: Keys are hidden (•••••) for security. Just paste a new one to replace it.

## Troubleshooting

**"API key not configured" error**
- Go to Settings → AI Settings
- Add at least one API key
- Make sure you copied the entire key

**"Credit balance too low" error**
- Your API key ran out of balance
- Go to the provider's website and add credits
- Or paste a new API key with balance

**App not responding**
- Make sure you're connected to internet
- Check that at least one API key is valid
- Try switching to a different provider in AI Settings
